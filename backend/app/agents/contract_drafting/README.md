# Contract drafting

`catalog.py` defines ten agreement types and mandatory fields in French, Arabic and English. `service.py` validates intake, creates unsigned drafts, optionally refines wording and exports DOCX. Missing facts produce questions, not invented terms.

These are project-authored structures, not approved legal forms. Private example contracts are not committed or treated as legal authority. See `docs/LEGAL_WORKSPACE.md` for integration.
